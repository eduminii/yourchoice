## 개요

**교과** | 사회 4학년 — 3. 경제활동과 지역 간 교류  
**단원/차시** | 합리적 선택이 필요한 까닭 (4/14차시)  
**성취기준** | `[4사03-02]` 경제활동에서 합리적 선택이 필요한 까닭을 이해하고 일상생활에서 합리적 선택을 실천한다.  
**활용 시간** | 약 15분 (개인 플레이) + 10분 (모둠 토의)

민준이의 하루를 배경으로 한 5라운드 소비 시뮬레이션입니다.
학생들은 각 장면에서 **가격·품질·디자인·필요성** 4가지 기준을 보며 선택하고,
예산 게이지와 만족도 게이지의 실시간 변동을 통해 합리적 선택의 필요성을 체감합니다.

---

## 게임 흐름

| 장면 | 상황 | 핵심 기준 |
|:---:|---|---|
| 1 | ✏️ 아침 — 학용품 코너 | 가격 vs 품질 |
| 2 | 🍱 점심 — 분식집 메뉴 | 가격 · 필요성 균형 |
| 3 | 🎮 오후 — 앱 스토어 | **필요성** ("꼭 필요한가?") |
| 4 | 🎁 저녁 — 친구 생일 선물 | 예산 잔액 연동 |
| 5 | 🏪 귀갓길 — 편의점 간식 | 충동 소비 vs 자제 |

선택 결과는 **예산 게이지 + 만족도 게이지**에 즉시 반영되며,
앞 라운드의 선택이 뒤 라운드의 선택 가능 범위에 영향을 줍니다.

## 주요 기능

- **예산 부족 선택지 비활성화** — 잔액이 현실 최저가 미만이면 선택 불가
  - 과자 잔뜩: 700원 미만 불가 (편의점 낱개 과자 최저가)
  - 문구 세트: 1,000원 미만 불가
  - 캐릭터 피규어: 2,000원 미만 불가 (다이소 캐릭터 피규어 최저가)
- **플로팅 텍스트 피드백** — 선택 시 `-1,500원` / `만족도 +3` 텍스트가 떠오름
- **칭호(배지) 시스템** — 최종 점수에 따라 5단계 칭호 부여
- **모둠 토의 발문 화면** — 게임 후 교사용 토의 질문 4가지 + 정리 발문 내장

### 칭호 기준

| 점수 | 칭호 |
|:---:|---|
| 85점 이상 | 👑 합리적 소비 마스터 |
| 65~84점   | 🔍 꼼꼼한 소비자 |
| 45~64점   | 👛 아쉬운 짠돌이 |
| 25~44점   | ⚠️ 충동구매 위험 신호 |
| 24점 이하 | 💸 위험한 충동구매러 |

## 사용 방법

### GitHub Pages로 배포 (권장)

```
1. 이 저장소를 Fork 또는 Clone
2. Settings → Pages → Source: main 브랜치 / root 폴더 선택
3. 저장 후 생성된 URL을 학생들에게 공유
   (예: https://your-username.github.io/minjun-game/)
```

### 로컬에서 실행

```bash
git clone https://github.com/your-username/minjun-game.git
cd minjun-game
# index.html을 브라우저로 바로 열기 (서버 불필요)
open index.html
```

### 수업 활용 방법

```
1. 교사가 전자칠판에 QR코드 또는 URL 제시
2. 학생들이 크롬북(1인 1기기)으로 접속
3. 약 15분간 개인 플레이
4. 게임 내 "모둠 토의 질문 보기" 버튼으로 발문 화면 이동
5. 10분 모둠 토의 진행
```
